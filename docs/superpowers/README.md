# Historical design records

The `plans/` and `specs/` directories preserve the rationale and staged plans
for earlier repository changes. Their dates, line numbers, proposed removals,
old tab/function names, and "ready for implementation" statuses describe those
historical snapshots, not the current production app.

Do not copy an old plan's code over the current implementation or remove these
records as if they were generated runtime files.

For current information use:

- [Production architecture, layout and deployment](../site-design.md)
- [Current Explore implementation](../explore.md)
- [Repository entry guide](../../README.md)
- [Agent guidance](../../AGENTS.md) — maintained by the update-harness workflow

These records are not loaded by the site and do not increase its browser bundle.
